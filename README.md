# NovaRaft

NovaRaft is a distributed real-time data replication engine for high-availability applications on scalable platforms.

NovaRaft is built to be simple and practical, focusing on doing one thing well.

**Why NovaRaft?**

- NovaRaft is a distributed real-time
- data replication engine for high-availability
- applications on scalable platforms

## Technology Stack

- rust
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/NovaRaft.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

NovaRaft is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
